Welcome — let’s set up your AI key

Your Node uses AI to write the editorial brief. Pick whichever provider you already have an account with (or pick whichever feels easier — both work just as well for this app). You only need one key. Cost is a few cents per brief.

Anthropic — Claude

default model: claude-haiku-4-5 · ~$1/$5 per million tokens

Get a key at console.anthropic.com → API Keys. Add $5 to Billing. Your key starts with sk-ant-.

OpenAI — GPT

default model: gpt-5.4-mini · ~$0.75/$4.50 per million tokens

Get a key at platform.openai.com/api-keys. Add $5 to Billing. Your key starts with sk-.

Your key stays on this computer in a file called .env. It’s never uploaded to GitHub. You can change it later via the “change api key” link top-right.
